# SI FORGE STUDIO 1.0.1

Simpler UI text and a compact start screen.

- Removed marketing slogans, decorative workspace headings, and sidebar filler.
- Centered the new/open project form and shortened its labels.
- Replaced headings with plain labels: Design, Backend, Database, Code, and Settings.
- Shortened default starter website text for new projects.
- Fixed canvas initialization when reopening an unlocked project.

Existing project files remain compatible. This update does not rewrite the text in existing websites.

## Download and run

Download **SI-FORGE-STUDIO-1.0.1-Windows-x64.zip**, extract the complete folder to a writable location, and open **SI FORGE STUDIO.exe**. Keep all files together. To use projects from a previous build, copy its `projects` folder into the new app folder. Keep your project password safe: there is no password recovery.

The Windows build is unsigned. V1 serves websites locally; public hosting is not included. Custom columns are text. Backend code nodes are synchronous trusted JavaScript, not an OS sandbox.

## Validation

Core tests, packaged desktop editor tests, and standalone website export tests passed on Windows. Start-screen and editor screenshots were visually checked. See VALIDATION.md for scope and limitations.
