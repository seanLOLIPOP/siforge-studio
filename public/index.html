Encrypted project

Your pages, backend flows, account hashes, assets, and database records are saved together using AES-256-GCM with a password-derived key. They are decrypted in memory while unlocked.

Custom backend code is trusted local code, not an OS sandbox. Encryption protects stored files; it does not hide a running project from the computer’s owner.

Portable workspace

Keep the whole app folder together. Projects are stored in projects/, beside the app. No external database, cloud service, or runtime installation is needed.

Export creates a separate runnable copy with its own encrypted project and bundled runtime. V1 serves websites locally; internet hosting requires a separate deployment.
